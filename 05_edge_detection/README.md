# エッジ検出と輪郭のフィルタリング

Cannyによるエッジ検出から、GaussianBlurによるノイズ低減、輪郭の取得、面積による絞り込みまでを学ぶ7本のサンプルです。番号順に実行して結果を比較します。

## サンプル一覧

| ファイル | 学習内容 | 確認するポイント |
| --- | --- | --- |
| [01_canny.py](01_canny.py) | Cannyエッジ検出の基本 | 白地の黒い長方形と円をグレースケールに変換し、閾値50・150で境界を検出する |
| [02_canny.py](02_canny.py) | Cannyの閾値比較 | 同じ画像で30・100、50・150、100・200を比較する。明暗差が大きい図形では結果が似ることもある |
| [03_canny_threshold.py](03_canny_threshold.py) | 明暗差と閾値の関係 | 黒・濃い灰色・薄い灰色の長方形で、背景との明暗差による検出結果の違いを見る |
| [04_gaussian_blur.py](04_gaussian_blur.py) | ノイズ低減の効果 | ノイズを加えた画像に直接Cannyを適用した結果と、5×5のGaussianBlur後の結果を比較する |
| [05_gaussian_kernel.py](05_gaussian_kernel.py) | カーネルサイズの比較 | 同じノイズ画像に3×3・5×5・11×11のぼかしをかけ、エッジの変化を見る |

| [07_contour_filter.py](07_contour_filter.py) | 面積による輪郭の絞り込み | 大小5つの図形から、小さい輪郭を除外して大きな図形の輪郭だけを赤く描く |

## 入力と実行方法

すべてのサンプルがコード内で画像を生成するため、外部画像は不要です。
04・05では乱数でノイズを生成するため、実行するたびに結果が多少変わります。

環境の準備は[トップREADME](../README.md)を参照してください。リポジトリ直下で実行します。

```powershell
.\.venv\Scripts\python.exe .\05_edge_detection\01_canny.py
.\.venv\Scripts\python.exe .\05_edge_detection\07_contour_filter.py
```

実行するファイル名を切り替えてください。画像ウィンドウにフォーカスを合わせてキーを押すと終了します。

## 処理の流れ

06・07では、次の順番で処理しています。

```text
画像の生成 → グレースケール変換 → GaussianBlur
→ Canny → findContours → 輪郭情報の取得・描画
```

07では、描画する前に面積条件を確認します。

| 関数・設定 | この章での役割 |
| --- | --- |
| `cv2.cvtColor()` | BGR画像をグレースケールに変換する |
| `cv2.GaussianBlur()` | 画像をぼかし、細かい明るさの変化を抑える |
| `cv2.Canny()` | 明るさの変化からエッジ画像を作る |
| `cv2.findContours()` | エッジ画像から輪郭の点列を取得する |
| `cv2.RETR_EXTERNAL` | 最も外側の輪郭だけを取得する |
| `cv2.CHAIN_APPROX_SIMPLE` | 輪郭の直線部分の点を間引いて保持する |
| `cv2.contourArea()` | 輪郭で囲まれた面積を求める |
| `cv2.boundingRect()` | 外接長方形の左上座標`x, y`と幅・高さ`w, h`を求める |
| `cv2.drawContours()` | 輪郭を描画する。BGRの`(0, 0, 255)`は赤色 |

## 学習のポイント

### Cannyの閾値とぼかし

Cannyの2つの閾値は、画素の明るさそのものではなく、明るさの変化の強さに対する値です。
低い閾値と高い閾値を使い、強いエッジと、それにつながる弱いエッジを判定します。
閾値を変えても、元画像の境界が十分に強い場合は結果がほとんど変わらないことがあります。

ぼかしを強くすると細かなノイズを抑えやすくなりますが、残したい細部や境界も弱くなることがあります。
05ではカーネルサイズを変え、ノイズの抑制と図形の境界の残り方を比較します。

### 「検出した輪郭数」と「条件を通過した輪郭数」

07の現在の設定は`MIN_AREA = 1000`です。次の条件で、小さい輪郭の描画をスキップしています。

```python
if area < MIN_AREA:
    continue
```

つまり、**面積が閾値以上の輪郭を描画**します。閾値と同じ面積の輪郭も対象です。

- `All Contours`：検出したすべての輪郭を赤く描画します。
- `Filtered Contours`：面積条件を通過した輪郭だけを赤く描画します。
- 端末の`検出した輪郭数`：`len(contours)`による、フィルタ前の輪郭数です。
- 端末の各輪郭の情報：条件判定より前に出力するため、除外される輪郭も表示します。

学習時に確認した面積は、76・192・31468・40390・101でした。この値を基にすると、結果は次のとおりです。

| `MIN_AREA` | 検出した輪郭数 | 条件を通過する輪郭数 |
| --- | --- | --- |
| 50 | 5 | 5 |
| 100 | 5 | 4 |
| 150 | 5 | 3 |
| 500 | 5 | 2 |
| 1000 | 5 | 2 |

**500でも1000でも、大きな長方形と円の2つに赤い輪郭が付くのが正常です。**
今回の面積には500以上1000未満のものがないため、この変更では採用数が変わりません。

現在のコードはフィルタ後の件数を端末には出力しません。`Filtered Contours`の赤い輪郭で確認します。
また、元画像のコピーに輪郭を描いているため、除外された小さい図形そのものは画像に残ります。
`contours`から要素を削除する処理でもありません。

面積は検出された輪郭から計算する値であり、図形を描いたときの理論上の面積や黒い画素数と必ずしも一致しません。

## この章でできるようになったこと

- エッジ画像と輪郭の点列の違いを理解する。
- 閾値やぼかしの大きさを変え、検出結果を比較する。
- 輪郭から面積・位置・大きさを取得する。
- 面積条件で、描画する輪郭を選ぶ。
